# Makalabox

**Makalabox** — это платформа для публикации и управления тематическими статьями, образовательным контентом и материалами. Проект используется как часть образовательной экосистемы и интегрируется с другими продуктами.

---

## 🧩 Технологический стек

Проект построен на современном frontend-стеке:

- ⚛️ **React** — библиотека для построения пользовательских интерфейсов
- 🧠 **TypeScript** — строгая типизация и безопасность кода
- ⚡ **Vite** — быстрый сборщик и dev-сервер
- 🎨 **ESLint** — контроль качества и стиля кода
